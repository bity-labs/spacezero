# Ideate

Interrogate the idea until we reach a shared understanding of what it is, why it matters, and what shape it should take.

Walk down the idea tree one branch at a time. Resolve dependencies between decisions before moving on.

For each question, provide your recommended answer or default position.

Ask questions one at a time.

If a question can be answered by exploring the codebase or project docs, explore instead of asking.

Stop when the idea is clear enough to either:

- specify
- design
- implement as a small experiment
- reject
- park for later
