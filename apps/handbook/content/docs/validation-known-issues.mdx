## What to update after each build slice

When a meaningful slice lands, update:

1. normative docs or ADRs if a durable rule changed;
2. relevant Handbook walkthroughs if the human mental model changed;
3. `Current Foundation` if status changed;
4. `Validation and Known Issues` if checks or expected failures changed.
