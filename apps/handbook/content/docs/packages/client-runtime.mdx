# Client Runtime

`packages/client-runtime`

## What it is

Browser-safe client runtime used by the Desktop renderer.

## What it does today

Wraps authenticated HTTP calls, streaming SSE connection behavior, Host connection setup, harness auth commands, Agent Runtime model catalog queries, Agent Resource skill descriptors, Project catalog client operations, and Project Session client operations including runtime configuration, interrupt, and durable follow-up queue methods.

UI consumes this package instead of talking to Host internals.

## Tech stack usage

TypeScript, Effect `4.0.0-rc.109`, browser `fetch`, SSE parsing/reconnect logic, Vitest, and `@spacezero/host-contracts`.
