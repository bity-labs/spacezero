# Space Zero Handbook

This handbook is the private product-owner memory for the Space Zero build.

Use it to answer questions like:

- What did we decide?
- What exists today?
- What is still deferred?
- Which part of the monorepo owns a behavior?
- What should we update when a build slice lands?

## Source of truth

Normative architecture, coding, and decision rules still live in the repository `docs/` folder.

The handbook should explain those decisions in practical language, link back to durable docs, and stay updated as we build. It must not redefine rules differently from `docs/`.

## Current build phase

Space Zero is in the v0.1 foundation phase: a separate Workspace Host, typed Host Protocol, managed Project Sessions, Pi Adapter, and a minimal Desktop shell are in place. The product UI and task-to-ship workflow are still thin.
